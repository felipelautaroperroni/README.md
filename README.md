# Trabajo Práctico 1 - Paradigmas de Programación (POO en Java)

## Descripción
Implementación de un sistema de administración de eventos universitarios en Java aplicando:
* **Encapsulamiento y modificadores de acceso**
* **Agregación:** Relación entre `EventoUniversitario` y `Sala`.
* **Composición:** Relación fuerte entre `EventoUniversitario` y sus actividades.
* **Herencia y Polimorfismo:** Jerarquía con clase abstracta `Actividad` y subclases concretas `Charla` y `Taller`.
* **Clase Asociativa:** `Inscripcion` vinculando `Estudiante` y `Actividad`.
